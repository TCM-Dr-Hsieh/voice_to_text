# 語音書寫

這是 Windows 本機語音書寫工具。預設是文章編輯器；另有「會議模式」，把演講、研討會、課程轉成標示說話者的逐字稿並即時翻譯。文章編輯器：把游標放在插入位置後，可以用本機麥克風、電腦播放聲音、遠端瀏覽器音訊，或上傳音訊檔產生文字。Qwen3-ASR 與 ForcedAligner 在本機背景程序執行；校稿呼叫設定的 OpenAI 相容聊天服務（預設 LM Studio）。

## 安裝（全新電腦）

**不需要預先安裝 conda 或任何 Python 環境。** 在全新的 Windows 電腦上，雙擊 `install.cmd`（或在 PowerShell 執行 `.\setup.ps1`）即可完成全部安裝：

| 步驟 | 內容 | 下載量 |
|---|---|---|
| 預檢 | Windows 64 位元、磁碟空間（≥ 20 GB）、NVIDIA 顯卡與驅動（≥ 570）、網路 | — |
| Python | 自動找 Python 3.12；找不到時**經你同意**用 winget 安裝（只裝給目前使用者，不需系統管理員） | 約 25 MB |
| `.venv` | UI 用的獨立環境（NiceGUI、httpx、SoundCard、PyAV…），版本固定在 `constraints.txt` | 約 250 MB |
| `.venv-asr` | **獨立的** ASR 環境，含 `torch 2.7.1+cu128` 與 Qwen3-ASR 相依套件（94 個固定版本，見 `requirements-asr.txt`，不借用任何其他環境） | 約 4 GB（其中 torch 3.3 GB） |
| 模型 | 從 Hugging Face 下載固定版本的 `Qwen3-ASR-1.7B`、`Qwen3-ForcedAligner-0.6B`，以及會議模式用的說話者聲紋模型（CAM++，28 MB）到 `models\` | 約 6.1 GB |
| 設定 | 寫入 `data\settings.json`（模型路徑；可順便設定校稿 LLM） | — |
| 健檢 | `tools\doctor.py`：環境、GPU、模型、麥克風、LLM 連線，並實際載入 ASR 辨識一次 | — |

**需要自備**：NVIDIA 顯卡（語音辨識在 CPU 上太慢，不建議）與驅動、網路、以及一個 OpenAI 相容的 LLM 伺服器（本腳本不安裝 LLM；在「模型設定」填入網址與模型，或安裝時加參數）。

```powershell
.\setup.ps1                                  # 全部自動；可中斷後重跑，已完成的步驟會略過、下載會續傳
.\setup.ps1 -LlmUrl http://192.168.1.10:8080/v1 -LlmModel my-model     # 順便設定校稿 LLM
.\setup.ps1 -HfEndpoint https://hf-mirror.com                           # 網路受限時用鏡像下載模型
.\setup.ps1 -ModelsDir E:\models                                        # 模型放在別的磁碟
.\setup.ps1 -SkipModels                      # 模型已另外放好：之後在「模型設定」指定資料夾
.\setup.ps1 -Force                           # 重建 .venv 與 .venv-asr
.\setup.ps1 -Dev                             # 另外安裝 pytest（開發用）
```

若直接執行 `.\setup.ps1` 被「執行原則」擋住，改用 `powershell -NoProfile -ExecutionPolicy Bypass -File .\setup.ps1`（`install.cmd` 已經這樣做）。專案路徑請盡量短（例如 `C:\voice-writing`），避免 Windows 260 字元路徑上限。其他參數見 `Get-Help .\setup.ps1 -Detailed`。安裝記錄在 `setup.log`；任何時候都可以用 `.venv\Scripts\python.exe tools\doctor.py [--smoke]` 重新健檢。

- 既有的 `.venv`、`.venv-asr` 若是疊加在其他 Python／conda 環境上，或基底 Python 已不存在，會被自動偵測並改建成獨立環境；改建前請先關閉語音書寫。
- 已有模型時（例如 `D:\models`）：把路徑填在「模型設定」（即 `data\settings.json`），安裝腳本會沿用，不重複下載。若同時指定 `-ModelsDir`，則以 `-ModelsDir` 為準。模型資料夾可用絕對路徑，也可用相對於本專案的路徑（預設 `models\Qwen3-ASR-1.7B`），後者讓整個資料夾可以複製到別台電腦。
- 模型版本固定在 `tools\download_models.py` 的 `MODELS`（commit SHA），逐檔大小與內容雜湊（權重 SHA-256、其餘檔案 git blob 雜湊）記在 `tools\model_manifest.json`；升級時改 `MODELS` 後執行 `.venv\Scripts\python.exe tools\update_manifest.py` 重新產生。
- 沿用的既有模型若與固定版本不同（例如別的版本或檔案損毀），安裝與健檢會**警告**但不強制改用；`download_models.py --check` 會以非 0 結束。預設只比對檔案大小；要核對**每個檔案**的內容雜湊：`.venv-asr\Scripts\python.exe tools\download_models.py --check --verify`，或 `.venv\Scripts\python.exe tools\doctor.py --verify-models`。

## 啟動

在此資料夾雙擊 start.cmd，或執行：

    .\.venv\Scripts\python.exe app.py --open

服務預設監聽 0.0.0.0:2020（所有網路介面）：這台電腦開 http://127.0.0.1:2020/，同一個網路的其他電腦開 http://這台電腦的IP:2020/（Windows 防火牆第一次可能會詢問是否允許）。**頁面沒有登入驗證**，能連到這個埠的人都能使用這台電腦的麥克風與電腦播放聲音、看到並修改模型設定；只想給本機用時，設環境變數 VOICE_APP_HOST=127.0.0.1。若該埠已被其他程式佔用，可用環境變數 VOICE_APP_PORT 改埠。`.venv` 和 `.venv-asr` 位於本資料夾；校稿服務需另外啟動。

## 書寫與音訊來源

文章只存在目前瀏覽器頁面，程式不會自動儲存。工具列可開啟、儲存、另存 TXT，並在未儲存時提醒。開始音訊前先把游標放到插入位置；若選取文字，本次成功辨識的語音會取代所選範圍。音訊處理中文章暫停手動編輯，畫面在固定插入點預覽校稿；完成後一次寫入，取消則還原文章。沒有成功定稿文字時，原文章與選取範圍保持不變。

選「音訊檔」後，上傳 WAV、MP3、M4A、FLAC 或 OGG，再按「開始轉錄」。它使用與即時音訊相同的固定視窗、重疊裁切和校稿流程，完成後插入文章。停止可處理已讀取的音訊；未讀取部分不再處理。音訊檔不另存錄音 WAV。

遠端麥克風與遠端電腦音訊由瀏覽器擷取並經同源 WebSocket 傳回主機；其他電腦使用時需要 HTTPS 及瀏覽器音訊授權。VOICE_APP_SHARED=1 會隱藏主機裝置和設定入口，只留下遠端來源與音訊檔。分享模式沒有登入驗證，入口仍須限制可進入的人員。

同一個瀏覽器分頁在遠端音訊連線短暫中斷時，會繼續擷取並暫存在該分頁。瀏覽器每 5 秒檢查連線；15 秒沒有伺服器回應時，即使 WebSocket 尚未通知關閉，也會嘗試重連。伺服器 20 秒沒有收到音訊或心跳，也會將舊連線視為失效。同一段錄音的新連線可安全接管舊連線，並在偵測斷線後 30 秒內補傳。伺服器用封包序號確認進度，重傳不會把同一段聲音重複寫入；錄音仍保存為同一個 WAV。按「停止並完成」會等待暫存音訊送完。若超過重連期限、暫存超過 32 MiB，或分頁被關閉／重新整理，音訊可能不完整；已收到的部分會標示為未完成。這項補傳只適用同一分頁及同一網址；若 cloudflared 重啟後換成新網址，必須重新開啟頁面。

首次載入 ASR 時，伺服器會定期回報準備中；尚未開始錄音就斷線時，同一分頁會用相同識別碼重送啟動要求。若伺服器連續 15 秒沒有回應，瀏覽器會嘗試重連；準備超過約 6 分鐘仍未完成時會停止等待，並解除文章編輯鎖定。

## 固定視窗辨識與三段校稿

設音訊視窗長度為 L、左側參考重疊為 Z。第 n 段音訊範圍是：

    [(n−1)(L−Z), (n−1)(L−Z)+L]

例如 L=9、Z=4 時，前三段為 0–9、5–14、10–19 秒。Overlap 沒有固定四秒上限，但須符合 0 ≤ Z ≤ L−3，讓每段至少有三秒新音訊。每隔 L−Z 秒產生一段新 ASR。停止或音訊檔結束時，如果還有新音訊，會辨識不足 L 的最後尾段；剛好停在完整視窗末端時不再重送只有 overlap 的尾段。停頓不觸發切段，沒有定時初稿，也沒有保留兩秒右側尾端。

每段 ASR 的完整重疊視窗和時間對齊保存在紀錄中。組成文章時，前一視窗已涵蓋的音訊歸前一段；程式用原始 ASR 的 ForcedAligner 時間，裁掉新視窗左側重複文字。校稿後文字不沿用 ASR 的逐字時間戳。視窗最後一個被切斷的字，ForcedAligner 常把它的時間拉到音訊長度之外；最後一個字的結束時間超出 0.8 秒以內視為這種情況，字照常保留、時間記為視窗結尾；其他字的結束時間、以及任何字的開始時間，只容許超出 0.2 秒，超過就當成對齊失敗（暫停，可重試或略過）。

每收到一段新 ASR，LLM 參考已鎖定前文，校正最多三段：「前兩段可修訂文字＋最新 ASR 新增文字」。第 1、2 段到達時也立即校稿並預覽。從第 3 段起，每輪回傳三段後，最舊的一段鎖定，剩下兩段可於下輪再校正；停止或檔案結束後全部鎖定。符合段號格式且沒有把非空段刪空的校稿結果會直接套用；回應格式錯誤、非空段回空白或請求失敗時會重試，仍失敗則保留目前文字並顯示警告。文章內容可在完成後直接編輯。

## 會議模式（演講、研討會、課程）

按工具列的「**會議模式**」，下方的文章框會換成左右兩欄：左欄「會議即時語音」是逐字稿（每段標示說話者），右欄「會議即時翻譯」是同一段的譯文，每一列左右對齊。適合有主持人、講者、學員輪流發言的場合。音訊來源與文章模式相同；要收「從這台電腦喇叭放出來的所有人聲」（例如每位學員用麥克風，聲音都從主控電腦的喇叭播出），選「電腦播放聲音」。

    語音#1(00:00-00:12) 王先生: 你好，我是王先生。          Voice#1 Mr. Wang: Hello, I am Mr. Wang.
    語音#2(00:12-00:23) 陳先生: 很高興認識你。               Voice#2 Mr. Chen: Nice to meet you.

匯出的雙語對照 TXT（和自動存檔的同名 `.txt`）在每段的「語音#n」後面附上這一段在音訊中的時間，從錄音開始算（一小時以上寫成 `1:02:01`）。時間是這一段新增音訊所屬的範圍，不是整個互相重疊的辨識視窗：第一段涵蓋完整的第一個辨識視窗；後續各段是該視窗相較前一個視窗新增的部分，長度通常等於每次產生新辨識的間隔（視窗長度減左側參考長度，也就是畫面上「每 N 秒產生新辨識」的 N，依「模型設定」而異）。上面的範例用預設值（視窗 12 秒、左側參考 1 秒）：第一段 12 秒，之後每段 11 秒。同一段有多位說話者時只有第一行附時間。畫面上不顯示時間，以免畫面太長。

**說話者**：程式用聲音自動分群，不需要事先註冊，也不假設有幾個人；有人說夠多話就多出一位。預設叫 `Speaker-001`、`Speaker-002`…。按左欄標題旁的「說話者」可以替每位輸入名字（左欄立刻改用，已寫的逐字稿也跟著改）；同一個人被分成兩群時，用「合併到」併回去。聲音無法判斷的句子顯示灰色的「不明」；「嗯」「對」這類太短的回應沒有可用的聲紋，也是「不明」。在「模型設定 → 會議模式」可開啟 LLM 補標：依上下文判斷「不明」的句子是誰說的，補標的句子在名字後面加 `*`（一階只在與聲音的弱傾向一致時才採用；二階較積極，預設關）。聲音已判定的說話者不會被改。

**說話者顏色**：左右兩欄的說話者名字和左邊的細色帶依說話者的編號上色：第 1 位用第 1 色、第 2 位用第 2 色…，共 10 色，用完就從第 1 色再來，所以一位說話者一整場都是同一個顏色（改名、合併都不會換色；「說話者」視窗的名字旁也有色塊）。「不明」和「背景」維持灰色。名字照常印出，顏色只是輔助。

**背景人聲**：麥克風有時會收到不是發言的私下交談。聲音**比最近的常態小聲、又不像任何已分出的說話者**的句子（兩個條件要同時成立）會標成灰色的「背景」：仍然顯示、也存進檔案（匯出的 TXT 標成 `[背景]`），但**不送去翻譯**，也不參與說話者的 LLM 補標。點灰色的「背景」可以取消（這句就當一般發言，會被翻譯）；點「不明」可以手動標成背景。只小聲、但聽起來像某位已知說話者的，仍算那位說話者；一個人若持續小聲說話（約 12 秒以上、4 句以上），會被當成一位說話者而不再是背景。開場約一分鐘還沒有「常態音量」可比，不判斷。可在「模型設定 → 會議模式」關閉，或調整「比常態小多少 dB」（預設 6）與「相似度上限」（預設 0.45），數字越小越保守。

**進階參數**：「模型設定 → 會議模式 → 進階參數…」會開一個視窗，列出說話者標記的全部數字（約 33 個，按階段分組：單位與句子、建立與更新說話者、句子標記與「不明」、背景人聲、文字補標），每個都標著預設值、範圍、功能，以及調高、調低會怎樣；用 ★ 標出最重要的幾個，有量測過的在說明下方附上「實測」（在 15 場標註錄音上，把這個數字調高、調低的結果）。「套用」會用和儲存設定一樣的檢查，「全部還原成預設值」回到預設，「取消」不改任何東西。只有和預設不同的數字才會寫進設定檔，所以之後預設值改良時，沒動過的會自動跟上。**修改只對下一場會議有效**，進行中的會議維持開始時的數字（也不能在會議進行中開設定視窗）。每場會議的 JSON 檔會記下那一場實際用的全部數字（`speakers.settings.tuning`）和其中不是預設值的（`tuning_changed`；關掉背景判斷時，背景相似度上限記為 0，因為追蹤器就是這樣跑的），之後改了設定或預設值，也看得出舊的會議是用什麼數字跑的。這些預設值是在少數模擬錄音上調的，換成真實的課堂錄音後可能需要重新調，建議一次只改一兩個，改完用 `tools\check_meeting.py` 或實際開一場會議檢查。

**翻譯**：右上角輸入要翻成的語言（直接打字，例如 English、日本語、Bahasa Indonesia；它會成為翻譯 LLM 的指示的一部分）和「延遲語音數」，按「開始翻譯」。翻譯用「模型設定 → 翻譯」的 LLM，預設沿用文字校稿的連線。翻譯分兩層。**最新 3 段**：每多一段，就把「已定稿的譯文（最近 5 段附原文）、最後 3 段的原文與目前的暫定譯文」交給模型，由模型輸出這 3 段的譯文，和逐字稿的三段滾動校稿同步；所以每一段會被翻 3 次，句子在下一段才說完時，模型會回頭修正前兩段的譯文。這些暫定譯文是**每段一整塊、不分說話者**（最新幾句是誰說的常常還沒定），右欄用黃色底表示還可能更動。**正式譯文**依說話者分段，比逐字稿慢 N 段（N 最小是 3，預設 6）：最新 3 段仍可能被校稿修改，所以只處理已定稿的段落，並在待翻的段落之外，另外讓模型讀到後續至多 N 段可用的原文。只有一位說話者、且暫定譯文就是從這段原文翻出來的段落，直接採用暫定譯文，不再多呼叫一次；有多位說話者、或沒有可採用暫定譯文的段落（例如翻譯是中途才開始、暫定翻譯失敗、原文後來被校稿改過）才會再依說話者分段翻一次。所以「延遲語音數」N 主要決定說話者名字何時出現：已有來源相符暫定譯文的單一說話者段落會直接轉正；多位說話者，或缺少可採用暫定譯文的段落，才會正式重翻，並在待翻段落之外另外附上後續至多 N 段可用的原文。按下「開始翻譯」時，已有的段落會分批一次補翻到「最新 − N」，之後每多一段就翻一段。暫定譯文失敗時，過一會兒會連同下一段再翻，不會卡住正式譯文。連續失敗的段落會顯示「（翻譯失敗）」，可按「重試失敗段落」（或重新按「開始翻譯」）再試一次。說話者名字會先翻成一張名字表，之後改名只會重翻名字，不會重翻整段。同一段裡換人時，譯文會保留說話者；之後說話者標記變動而使分段不同的那一段會自動重翻。

**儲存與匯出**：會議進行中每 20 秒（可調）自動存到 `data\meetings\會議-日期-編號.json`（完整紀錄）和同名 `.txt`（雙語對照）；瀏覽器暫時斷線不會中斷會議，頁面關閉後約 5 分鐘才會結束。按「匯出雙語對照 TXT」可下載目前的內容。即時來源預設一併儲存錄音 WAV。

**限制與提醒**：
- 新增依賴：`onnxruntime`、`kaldi-native-fbank`、OpenCC，以及 28 MB 的聲紋模型（`install.cmd` 會一併安裝）。沒有聲紋模型時會議仍可使用，但不標說話者。
- 聲音很相近的兩個人可能被併成一群，目前只能合併、不能拆開；說話很少的人（只問一兩句）可能不足以成為一群，會被標「不明」。
- 對話快速輪替時「不明」可能占兩成左右，大多是太短的回應；開啟 LLM 補標可以減少。
- 背景人聲只抓得到「小聲、不像任何人」的：在標註錄音上抓到約 85%、約 0.5% 的正常發言被誤標（多半是特別小聲的人）；貼著麥克風、音量正常的私語，以及壓在發言者底下同時發生的交談抓不到。被誤標的句子點一下就能取消。這些數字來自家人朋友模擬看診的錄音，不是真實課堂，僅供參考。
- 說話者標記與翻譯都會把文字交給你設定的 LLM（區網內的服務不會把資料送出去）。
- 在 15 場有人工逐句標註的模擬錄音（2–3 人）上，字級精確率約 99.6%、涵蓋約 93%，群數 15 場全對；兩個訪談節目樣本（3 人、5 人）也分出正確的人數。這些錄音量少、不是真實會議，數字僅供參考。可用自己的錄音檢查：`.venv\Scripts\python.exe tools\check_meeting.py 錄音檔 --minutes 10 --translate English`。

## 設定與資料

data/settings.json 保存視窗長度、Overlap、模型路徑和校稿連線資訊。讀取舊設定檔時會忽略已移除的初稿間隔、停頓門檻、音量門檻和校稿最大改動比例。API Key 以本機明文儲存，不包含於語音紀錄。

「儲存錄音」只適用即時來源，會把連續 16 kHz WAV 和同名完整紀錄 JSON 寫入 data/recordings/。音訊檔來源和未開啟儲存錄音的來源可在頁面匯出本次 JSON；書寫文章仍需另外儲存 TXT。辨識或對齊失敗時保留片段供重試；可略過對齊失敗的片段，紀錄中保留可能缺漏的時間範圍與原始診斷。

## 驗證

    .\.venv\Scripts\python.exe -m pytest -q                      # 需要以 setup.ps1 -Dev 安裝 pytest
    .\.venv\Scripts\python.exe tools\doctor.py --smoke           # 環境、模型、麥克風、LLM 健檢，並實際辨識一次
